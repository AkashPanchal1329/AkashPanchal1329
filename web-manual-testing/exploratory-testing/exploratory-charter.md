# Exploratory Testing Charter

## Mission
Explore a business-critical web workflow to identify functional, usability, validation and data-consistency risks.

## Timebox
60 minutes

## Areas
- Navigation
- Required fields
- Boundary values
- Role permissions
- Refresh/back behavior
- Duplicate submissions
- Network interruption
- Browser compatibility
- Error handling

## Evidence
Capture clear reproduction steps, screenshots where appropriate, expected vs actual behavior, severity, impact and test environment.
