# QA Test Documentation

A reusable library of generic QA documentation examples.

## Included

- Test plan
- Test scenarios
- API test cases
- Regression checklist
- Bug report template
- Test summary report

## Quality principles

Good QA documentation should make it easy for another tester or stakeholder to understand:

1. What was tested
2. What was not tested
3. Which risks were identified
4. Which defects were found
5. What evidence supports the findings
6. Whether the build is ready for the next stage
