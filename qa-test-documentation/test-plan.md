# Sample Test Plan

## Objective
Validate a web application's critical business workflows before release.

## Scope
- Authentication
- Core CRUD workflows
- Search/filter
- Validation
- Role permissions
- File upload
- API integration
- Regression

## Out of Scope
Performance/load testing unless explicitly included in the release scope.

## Test Types
- Functional
- Integration
- Smoke
- Regression
- Exploratory
- Negative
- Compatibility

## Entry Criteria
Build is deployed, requirements are available, and test environment is accessible.

## Exit Criteria
Critical workflows pass, no unresolved blocker/critical defects remain, and agreed regression coverage is complete.
