## 👨‍💻 About Me

I’m **Akash**, a software QA engineer focused on practical, risk-based testing. My approach combines thoughtfully designed manual test cases with maintainable automation and clear defect reporting.

Whether I’m validating a critical user journey, checking negative API scenarios, or preparing regression coverage, my goal is the same: **make quality visible, measurable, and repeatable**.

> **My QA philosophy:** Test what matters, document what fails, and make it easier to ship with confidence.

## 🔍 How I Approach Quality

```text
Understand requirements
        ↓
Identify risks and critical journeys
        ↓
Design scenarios and test data
        ↓
Execute functional + negative tests
        ↓
Automate repeatable checks
        ↓
Run regression and report findings
        ↓
Share actionable quality feedback
```

**What you can expect from my work:** clear test coverage, reproducible bug reports, readable results and attention to real user impact.
