# Mobile Test Checklist

- [ ] Fresh installation succeeds
- [ ] Upgrade installation preserves expected data
- [ ] Application launches without crash
- [ ] Login succeeds with valid credentials
- [ ] Invalid credentials are handled
- [ ] Keyboard does not hide required controls
- [ ] Back navigation behaves correctly
- [ ] App handles portrait/landscape as required
- [ ] Network loss displays an understandable state
- [ ] Wi-Fi to mobile-data transition is handled
- [ ] Permissions are requested at the correct time
- [ ] Session timeout is handled
- [ ] Logout clears protected access
- [ ] UI is usable on different screen sizes
- [ ] No obvious layout overlap/cutoff is present
